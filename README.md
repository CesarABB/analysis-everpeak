EverPeak Retail Analysis – Sprint 7

  Este repositorio contiene el análisis realizado durante el Sprint 7 del caso EverPeak–SilverBasket.

  El dataset everpeak_retail incluye 2,000 órdenes de clientes con valores faltantes, sentinels, outliers y problemas de calidad
  diseñados para simular datos reales del retail. :contentReference[oaicite:2]{index=2}

  notebooks/everpeak_analysis.ipynb → Notebook principal con limpieza, EDA, distribuciones, outliers y conclusiones.
